Página principal del consultorio

Administra citas y consulta los módulos del Centro Médico desde un solo lugar. Selecciona una opción para comenzar.

Registrar citas médicas

Busca al paciente y verifica la disponibilidad antes de registrar la cita.

Cancelar cita médica

Identifica la cita y revisa los datos antes de solicitar la cancelación.

Importante: una cancelación real debe mostrar un resumen y pedir confirmación.

Registrar paciente

Registra los datos básicos de identificación y contacto.

Registrar consultorio

Identifica el espacio físico y su disponibilidad.

Registrar empleado

Propuesta académica para registrar información básica del personal.

Esta pantalla se conserva de los prototipos anteriores. El modelo actual no incluye una tabla de empleados y esta demostración no almacena datos.

Registrar medicamento

Interfaz de propuesta para describir medicamentos.

La prescripción corresponde a profesionales autorizados.

Registrar tratamiento

Propuesta para documentar un tratamiento indicado por un profesional autorizado.

No uses esta demostración para decisiones clínicas ni para datos reales.

Registrar médico

Registra información profesional básica en esta interfaz demostrativa.

Estado del prototipo

La aplicación permite recorrer las interfaces y probar la validación básica de campos obligatorios.

Los formularios no guardan datos ni se conectan a una base de datos. La accesibilidad debe comprobarse mediante pruebas.
